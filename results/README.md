## 2. 채택하지 않은 실험

| 실험 | 결과 | 결론 |

| RL β = 200 | 20/40 vs v3 | 효과 없음 |
| RL β = 500 | 학습 중 승률 0.00까지 붕괴 | V가 GA 판단을 덮어써서 불안정 |
| GA 3차: 11특징 그대로, 상대만 v3·v4·챔피언 | 44/100 vs v5 | 숫자만 다듬는 방법은 한계 |
| 2수 앞보기 빔 5 vs 빔 3 ※ | 7/20 | 넓은 빔이 더 낫지 않음 → 빔 3 유지 |
| 2수째 점수만 사용 ※ | 0/12 vs 1수 v3 | 1수째 `eroded_cells` 가점이 빠져 줄 삭제를 회피 |
| 빠른 중력 대비 (재계획) ※ | 계획과 다르게 놓인 비율 1/3,820 | 필요 없음 → 구현 안 함 |

※ 표시는 개발 중 학습용 대결기(`src/arena.py`)로 v3 가중치를 써서 측정한 값이다.
